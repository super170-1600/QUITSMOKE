# 字体与空间排版、交互性能优化

## 视觉修改

- `src/styles/readability.css`：移除全元素强制同色的覆盖，恢复正文、辅助文字、暖金选中状态、白色按钮与错误反馈的层级。使用系统字体，不增加字体下载。
- 打卡输入与数据详情放大有效数字和必要字段，减少细小字号；日期、范围切换、备注及说明统一间距。
- 个人中心收紧晶片与设置入口的距离，控制设置阅读宽度，主入口中文标签提高至 15px。
- 成就页改为非对称主读数与光学封印展示，五个阶段使用不同星芒/刻度，减少重复卡片容器。`AchievementSeal.vue` 为轻量 SVG，无新增 WebGL 场景。
- 内容型悬浮面板按内容高度展开，避免多余的底部空白；手机保留内部纵向滚动。
- 封面、主晶体和星图的背景及材质不变。现有数据、API 与权限不变。

## 性能修改

- `resizeSurface.ts`：数据圆盘、星图、光环只在真实尺寸变化时设置画布尺寸，避免每帧清空并重置绘图缓冲区。
- `overviewScene.ts`：玻璃面板和凹槽之间不随圆盘旋转变化的对齐误差只计算一次，避免每帧重复遍历约 196 个采样位置。
- `OpticalHaloScene.vue`：按视觉字段生成稳定签名，不因备注或后端元信息变化而重新建模；连续视觉输入合并到同一个动画帧。
- `hubAssetScene.ts`：标签页隐藏时停止动画调度，返回可见时恢复；保留此前“业务面板打开时暂停背后的晶体渲染”的修复。
- `main.ts`：由完整注册 Vant 改为仅注册实际使用的七个组件，并按需引入样式，保留 Toast 与确认对话框样式。

## 构建与验证

- 优化前入口 JS：1,376.53 kB，gzip 393.85 kB。
- 优化后入口 JS：1,182.64 kB，gzip 326.68 kB；入口 JS 约减少 194 kB（14%）。这不是全站资源总量或帧率指标。
- 52 个测试文件、230 项测试通过；生产构建通过，仍有较大入口和 Three.js 包的构建提示。
- 浏览器验证覆盖真实拖动时渲染继续但画布尺寸写入次数不增加、备注输入不增加光环构建次数、模块后台暂停恢复、320/390px 布局与既有业务流程。
- 浏览器测试使用隔离回执和示例数据，不登录真实账户，不写入线上数据库。未声称用户设备已达到固定 FPS；实际设备温度、显卡和网络仍会影响体验。
