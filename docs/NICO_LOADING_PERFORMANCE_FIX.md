# 打卡加载与渲染修复

本次保持数据库、API 契约、认证、角色权限及统计公式不变。

## 线上只读检查

检查用户提供的 CloudBase 部署：入口 HTML、打卡模块脚本、模块容器脚本、晶体 GLB、HDR 环境贴图均返回 HTTP 200，响应类型正确。当前没有登录线上真实账户，不能据此排除账户接口异常。

## 已定位问题与修复

- `CheckinView.vue` 原先串行等待完整历史统计，再查询当日记录。现在两者独立加载，当日表单不等待历史；历史失败时档案入口明确提示并可重试。
- 当日与历史读取加入 15 秒界面等待期限。读取失败保持错误状态，不把失败伪装为零支或无记录；不对保存操作应用超时包装。
- 损坏的本地草稿不再阻断真实记录加载。
- `HubView.vue` 原先在悬浮业务面板背后持续运行晶体动画。现在模块转场完成后暂停，只保留最后一帧；返回晶体后恢复，不改变背景与模型外观。
- `OpticalHaloScene.vue` 不再在圆盘旋转的每一次渲染中重复设置 canvas 尺寸。
- `HubBusinessModule.vue` 异步模块提供加载中与资源加载失败反馈，20 秒后显示重新加载入口。
- `smoking.ts` 保留历史请求开始后已确认的逐日读取和保存，避免迟到的历史响应覆盖新记录。
