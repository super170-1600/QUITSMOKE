### 兼容策略与边界

保留原 schema、API 请求字段、1–5 图表和所有统计公式。新数据存储在现有 note 字段，格式 `@nico/v1:` + JSON `{score,mood,note}`；JSON 是真实数据而非视觉参数，同一表同一行，无第二套数据源。读 API 统一解码，还原纯文本 note，额外暴露 craving_score/mood。旧纯文本记录保持原状，旧 1–5 分不会声称是新的 0–10 评分；编辑旧记录必须明确选择新强度与感受。新强度通过 `1 + round(score * 4 / 10)` 生成旧字段兼容值，其他模块仍使用旧字段。

备注上限 160 字，并在序列化后执行既有 300 字符限制；特殊转义导致超长会显示明确错误，不截断。时区沿用现有设备本地日历规则；项目当前没有用户档案时区字段。跨设备更换时区与服务端校验一致性属于现有系统限制，必须明确说明，不声称已支持档案时区。

独立 SQL 补丁只准备不部署，不改现有建表脚本、RLS、家庭事件触发器。回滚只移除新增校验触发器与函数，不删除记录；旧客户端回滚前需保留解码适配，避免直接展示版本化 note。未运行生产 SQL，服务端校验与真实持久化必须在部署环境继续验收。

## 逐阶段记录

Phase 1：日期读取与幂等保存、加载/失败/账户保护、未保存草稿拦截、历史范围校验。

## 实施文件与阶段证据

### Phase 1

- `src/views/CheckinView.vue`：重构打卡页；选日期时重新读取真实行，空日清空表单；失败/加载/提交锁定；三种草稿决策、路由离开保护与刷新提示。草稿按账号 + 日期保存在 sessionStorage，使用现有账户清理前缀。
- `src/stores/smoking.ts`：新增 loadDailyCheckin/saveDailyCheckin，按所选日期查询及更新，唯一键冲突后重新查同一天；沿用原缓存重算与账户 revision。旧 saveTodayCheckin 调用保留，历史日期或新量表转到安全日期保存。
- `src/api/checkin.ts`、`src/types/database.ts`、`src/types/domain.ts`：兼容读解码和可选新字段，原字段与查询列不变。API 不将封装 JSON 显示给其他模块。
- `src/utils/dailyPulse.ts`：版本化真实数据编码/解码、枚举、日期范围与窗口计算。
- `docs/nico_checkin_validation_patch.sql`：服务端校验补丁及回滚，不部署、不迁表。日期采用 Asia/Shanghai 的部署草案；须先统一服务端与客户端时区规则。
- Phase 1 检查：141 项单测通过，修正测试使用项目不支持的 Array.at 后类型检查及构建通过。隔离 API 持久化测试随后纳入完整验收。

### Phase 2

- `src/visuals/haloVisual.ts`：确定性映射、统一暖白/银蓝/暖金/柔灰蓝 tokens；空日无亮环，旧分值不转换成假新分值；固定槽位函数。
- `src/components/DailyHalo.vue`：独立 SVG 渲染契约、文字标签、选中描边、低动效静态纹理。
- 主表单顶部显示呼吸光核；未保存的形态预览明确标注，档案只使用已存记录。
- Phase 2 检查：145 项单测与生产构建通过。

### Phase 3

- `src/components/HaloArchive.vue`：固定四层轨道，每层七个日期节点，从内向外、12 点起顺时针；按 28 天回溯。节点详情提供日期、支数、强度、感受、备注、状态和编辑/补签。
- 月历和日期条使用同一 selectedDate；档案的 detail focus 是临时详情焦点，点击“编辑/补签”后同步 selectedDate 并加载真实表单。窗口补签前后坐标相同。
- 档案和月历通过 Teleport 独立浮层，避免被 3D 转场的 transform 裁切；Tab 焦点约束、Escape 仅关闭当前弹层，节点原生按钮支持 Enter。
- 手机 48×54px 节点命中区域；轨道最小宽度 440px，独立横向滚动以保留触控尺寸，不使页面横向溢出。不是在手机上强行缩小全部节点。
- Phase 3 检查：28 槽、各环七节点、坐标不变、跳转、分页、手机及横屏自动浏览器检查通过。

### Phase 4

- 新测试：dailyPulse.test.ts、haloVisual.test.ts、stores/dailyPulse.test.ts、stores/dailyPulse.persistence.test.ts。
- 新脚本：`scripts/verify-daily-pulse.mjs`；更新旧 `verify-hub-phase4.mjs` 适配新表单及新 action，保持其他模块回归。
- 最新完整 Vitest：36 文件、148 测试通过。生产类型检查及构建通过。仅存在原有较大包与混合动态/静态导入提示。
- 新浏览器 QA：16 项检查通过，包含纽约时区 DST 与本地跨日检查，结果见 verification.json。
