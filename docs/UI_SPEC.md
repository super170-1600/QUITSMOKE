# UI 设计规范

## 产品原则
- 主界面降低压力，不使用“失败、清零、重新开始”等措辞。
- 每日打卡目标：10 秒内完成。
- 首页只突出连续无烟、今日状态、累计少吸、累计节省。

## 视觉
- 白色卡片 + 浅灰页面背景。
- 主行动使用低饱和绿色。
- 圆角 18-20px。
- 主数字 48-64px；普通指标 22-28px。
- 不做游戏化排行榜。

## 页面
1. Login：品牌、邮箱、密码、登录/注册。
2. Home：计划天数、连续无烟大卡、四个统计卡、今日打卡按钮、7天改善概览。
3. Checkin：支数 Stepper、烟瘾 1-5、备注、提交。
4. Trend：7/30天趋势、baseline 对比。
5. Family：默认展示“戒烟进度 + 家庭动态”，支持轻量文字消息、快捷鼓励与系统事件；成员和邀请码位于次级页签。
6. Profile：昵称、角色、基线、家庭、退出。
