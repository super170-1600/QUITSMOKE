# Phase 1.5 — 晶体视觉质量重构

本阶段只调整 Three.js 视觉。未修改 Hub Vue 布局、路由、权限、业务 store、数据库、API、认证和统计公式；未引入依赖。无拖动、磁吸、模块点击或展开。保留其他未提交文件。

## 检查发现与处理

旧场景的每个面都有独立透射材质和一层白色高光，六个主面另有宽凸起边框；每条边同时绘制金属圆柱和亮线，背面结构透出。环境主要为均匀底色和五块灯箱，镜面反射层次不足。香烟端部为完整灰色圆柱加 28 个近似同尺度颗粒，标识尺寸较大。

改成两个合并的光学壳网格（主面 / 过渡切面），移除白色高光覆盖层、宽内框、双重边线和加法光斑。主面只保留一条窄的抛光边缘，朝向背面时隐藏。玻璃采用 FrontSide、depthWrite=false，不再将全部背面结构通过透明窗口叠加；实体香烟和碎片由不透明阶段绘制，丝带/粒子关闭深度写入。主面与过渡面的受控 alpha 配合物理透射，仍是实时视觉近似，不能等同于完整实体玻璃的多次内部折射。

## 几何与标识

六个主面保留原模块 ID，平面法线增加约 3–6 度小倾角；主面距离不等。十二条候选边切使用 0.72–1.30 的法线权重与 0.11–0.24 的不同切深；八个候选角切也使用不同权重与深度。自动排除被其他切面覆盖的两个冗余角切，最终为 **6 个主面 + 12 个边切 + 6 个角切 = 24 面**。几何仍封闭，各边恰好由两个面共享；每个主面面积大于 3 平方场景单位。

可选面的几何仍为平面。视觉壳上增加轻微法线滚动，模拟抛光切边的反射变化，导航所需的原始面中心、法线与顶点不变；这是着色近似，不是把可选面变成曲面。

五种模块造型保留，显示缩放至原来的 62–67%，上移至面局部 y=0.58，深度 z=-0.018；银色与暖金材质金属度/粗糙度调整至 0.75/0.26 和 0.72/0.28，减弱黑亮对比。04 无图形、标签或入口。

## 香烟、烟雾与粒子

香烟保留立体滤嘴、纸身、纸缝和接缝，局部自然倾角 z=.64，中心附近 x=-.16、y=-.10。末端纸边撕裂深度增加，完整厚灰柱改为薄断面。

黑色碎片改为一个 InstancedMesh 的 180 个实例：22 个粗块、48 个中块、110 个细粒。尺度约 .002–.040，密度由断面向外渐疏，带非均匀缩放和确定性的随机旋转。它们保持封印状态，不开发消散业务或点击动画。

烟雾改为三条平滑的半透明银白带与三条细玻璃纤维，围绕末端上升；少量条纹、边缘与视角反射由丝带着色器生成。另有 24 个 Points 微粒，以非常缓慢的角向/纵向运动连接流线。尊重减弱动画，固定截图不运动，隐藏页面不渲染。

## 验证与性能

- `npm test`：27 文件、121 项通过。几何测试保留主面面积下限、稳定 ID、法线、无退化面和闭合边检查，另验证五个标识及 04 空白。
- `npm run build`：通过。仍存在原有大包和混合静态/动态导入警告；Hub 场景包约 20.30 KB（gzip 7.71 KB），上阶段约 15.97 KB（gzip 6.48 KB）。主要增加带状着色器、粒子与合并几何工具，没有新依赖。
- 浏览器：12 桌面角度、390 × 844 手机、WebGL 上下文丢失、原 Landing 及九个匿名受保护路由检查通过，无未处理脚本/着色器错误。
- 当前主视角在 DPR=1 的 headless Edge 中，每帧计数为 **73 次调用、28,244 个三角形、24 个 Points**，包含透射阶段的重复绘制。其他固定角度为 33–57 次调用。计数在每次 render 前重置；并非 FPS 或硬件性能承诺。上阶段未记录相同口径计数，因此不声称某个百分比提速。
- 壳几何由逐面绘制合并为两份，删除逐面叠加高光和多层边框；细碎片增加但仍为一次实例绘制。DPR 上限仍为桌面 1.75、手机 1.4，低端设备的实际帧率需要设备验收。
