# QUITSMOKE Phase 3：入口与切面转场

## 当前交互：共用背景的直接悬浮面板

按本轮确认，原先的“切面扩大 → 整页交接”已改为直接浮出面板。`App.vue` 在 Hub 和来自 Hub 的功能路由之间持续保留同一个 Hub 实例、Three.js 画布和晶体朝向。功能内容作为前景圆角面板，内部可滚动，入场仅有 0.18 秒透明度淡入，没有位移或缩放。面板打开时背景设为 inert，关闭按钮、Escape、浏览器后退返回原场景。面板内的现有业务导航也继续使用该共用背景；认证及 onboarding 跳转不受覆盖层阻挡。

开发样板和正式业务仍分别遵循前文所述边界。刷新模块深链仍直接渲染模块，不强制重建其之前的 3D 入口。以下切面展开分镜属于上一版记录，当前不再播放。`scripts/verify-hub-phase3.mjs` 已改为校验共享画布 identity、面板只有一个、没有中间 morph 面板、姿态不变及返回行为。

面板入场光效补充：一次 0.44 秒淡入，配合 9px 浮起与 1.4% 的轻微缩放；银蓝/暖金边缘反射及柔和扫光同步启动，0.64 秒内结束，不延迟功能内容挂载、没有第二个路由动画。光效层不接收指针事件；减少动态效果偏好下全部禁用。背景晶体始终保持原位。构建与转场回归通过。

当前节奏进一步调整为面板 1 秒、边缘和扫光 1.1 秒。面板从点击确认时就出现，路由守卫和异步组件加载期间显示“正在准备内容”及无数据含义的骨架；加载完成后替换同一面板内的内容，面板不卸载、不重播动画。模拟组件加载延迟 900ms 的浏览器验证通过，并核对前后面板 DOM identity 一致。业务页面挂载后的数据请求仍沿用原有加载与错误处理，没有以动画时长判断数据是否就绪，也没有人为推迟请求。

## 本轮实现

保留封面现有香烟消散动画，结束后的目标由 `/home` 改为受保护的 `/hub`。未登录时通过现有守卫进入 `/login?redirect=/hub`；家庭和戒烟资料初始化继续遵循原有规则。

Hub 的已聚焦功能面通过点击、Enter 或空格激活。选中面连同立体标识向前脱离、扩大；其他外壳面降低透明度权重；随后交接到银白圆角面板，进入现有功能路由。面片动画约 0.78 秒，面板从 0.24 秒开始接入。采用独立面网格位移、缩放与 DOM 叠加交接，并非实时重建多面体拓扑。相机保持稳定，不缩小整个场景。

展开时晶体控制区设为 inert，键盘模块按钮禁用，避免重复激活。可取消或跳过动画；减少动态效果偏好下直接完成定位与交接。模块页提供“返回晶体”和 Escape 返回；浏览器后退同样触发反向收回。只缓存 Hub 视觉组件，离开时暂停帧循环，返回时复用场景并恢复所选面与四元数及键盘焦点。

会话转场信息只保存在内存。刷新或直接打开功能路由不补播展开动画，不显示依赖上一步操作的覆盖层。现有业务组件和 store 继续负责真实数据；没有缓存业务页面组件或新增账户数据持久化。

## 路由复用和差异

| 功能面 | 请求的现有路径 |
| --- | --- |
| 打卡 | `/checkin` |
| 数据 | `/trend` |
| 成就 | `/home` 的既有里程碑展示 |
| 互助 | `/family` |
| 个人中心 | `/profile` |
| 04 | 无路径、不可激活 |

桌面模式对 `/home`、`/trend`、`/family`、`/profile` 的既有 `/dashboard` 归并仍然生效；支持者的打卡限制及 onboarding 跳转保持原样。本阶段没有独立成就业务页，没有把桌面 dashboard 拆成五个新模块。模块内部绿色业务样式仍是原实现，Phase 4 再进行内容 UI 重构。

开发预览使用 DEV-only `/__hub-module/:face` 展示没有真实业务数据的转场样板，参数只允许五个可用 faceId。正式 `/hub` 始终进入原有受保护功能路径，开发样板没有绕过它们的权限。直接访问开发样板时提供回到晶体预览的链接。

目前模块内重新挂载时，本地表单/滚动状态依照原组件行为；已进入 store 的业务数据仍保留，尚未新增跨路由未提交表单缓存。没有小晶体角落返回装置，采用普通语义返回按钮。

## 返回后再次误进入修复

复现条件：确认进入模块，返回晶体，再把鼠标移到晶体主面。原控制器持续保留 `activated=true`，hover 更新重发该状态，使 Hub 再次请求展开。现在确认作为一次事件：回调收到确认快照前，控制器清除持久状态中的激活标志，后续 hover 不会重新进入。

修改 `src/visuals/hubInteraction.ts`，在 `scripts/verify-hub-phase3.mjs` 增加返回后实际鼠标移动检查。该用例修复前失败，修复后随转场回归通过；130 项测试及构建通过。
