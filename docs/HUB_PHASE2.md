# QUITSMOKE Phase 2：晶体交互

## 交付范围

在 Phase 1.5 的 Blender GLB 场景上接入独立交互控制器，保留外壳、内部封印、光子轨道和五个标识。没有新增依赖，没有修改数据库、API、统计公式、认证、权限或业务页面。本阶段点击只选择或确认功能面，不进行切面展开、业务跳转或页面转场。

## 操作和行为

- 鼠标或单指拖动晶体，释放后短暂惯性衰减，再磁吸到最接近视线的可用主面。
- 点击侧向主面使其转到正面；再次点击正面主面确认选中。确认状态使用轻微暖色反馈。
- 方向键切换五个可用面，Enter / 空格确认，Escape 回到初始观察角度。
- Tab 可进入晶体控制区及五个语义按钮；按钮仅在键盘焦点进入时显示，不构成默认侧栏。
- 04 保留空白且不参与选择或磁吸。过渡切面不能导航，射线命中前方过渡面时不会穿透选择后方功能面。
- 初次显示极小的“拖动旋转”提示，发生拖动或选面后在本次访问中隐藏。
- 减少动态效果偏好下跳过惯性和翻面过渡，直接定位。触控区域随晶体投影边界更新，不占满页面。

拖动阈值为 7 CSS px；旋转系数为 0.007 rad/px；速度限制为每秒 3 rad；释放后的惯性最长 0.18 秒，按 exp(-14 × dt) 衰减；磁吸采用 0.42 秒 cubic-out 四元数插值。定位保持当前滚转方向，没有加入强制图标朝上的二次校正。

稳定 faceId、navigationNormal 和可分离的资产结构均继续使用。控制器负责交互状态，Vue 负责轻量提示，Three.js 场景负责反馈及统一帧循环。空闲时不会新增晶体自动旋转。

## 验证结果

- `npm test`：30 个测试文件、128 个测试通过。
- `npm run build`：通过。仍存在构建包超过 500 kB 和已有混合静态/动态导入提示，没有构建错误。
- `node scripts/verify-hub-interaction.mjs`：五个面的键盘选择与鼠标确认、方向键循环、拖动不误确认、惯性停止、移动触控均通过；无捕获到的浏览器或 Shader 错误。
- `scripts/verify-hub.mjs`：12 个静态角度/面、移动布局、WebGL context loss 回退通过。
- 匿名权限回归：`/hub`、`/home`、`/checkin`、`/trend`、`/family`、`/profile`、`/dashboard`、`/setup`、`/family/setup` 均保留登录保护；公开封面可访问。

浏览器验证使用 Headless Edge，桌面 1440 × 900，移动 390 × 844；移动交互通过 CDP 发送触摸事件。这是模拟设备验证，不是实体手机测试。没有使用真实账号写入业务数据，没有将匿名路由检查表述为完整的已登录业务回归。
