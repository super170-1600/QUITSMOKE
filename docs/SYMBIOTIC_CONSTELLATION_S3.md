# 共生星图 S3 — 打卡与共同计划联动样板

2026-10-13。仅完成 S3；等待本阶段验收，未进入 S4 / S5。

## 体验

开发预览 `http://127.0.0.1:5173/#/__constellation-demo`：

- 点击中央核心打开日期打卡浮层；无需登录即可使用独立的本页模拟记录。
- 点击下方计划弧线创建计划；四类目标在编辑器中切换。
- 模拟身份可切换为支持者，体验提议和加入陪伴；没有代打卡或代确认入口。
- “读取本人记录”只使用已登录账号。未登录提示登录；不会自动写入或为测试伪造认证。
- 实际保存真实打卡须由用户在浮层中明确提交。共同计划始终标注模拟，即使核验使用本人真实记录，也不写计划数据库。
- 模拟记录、计划及草稿仅在当前页面实例存活；刷新或离开页面即清除，不影响之前的 Daily Pulse 测试数据。

## 完成项

### 打卡

- 暗场场景保持可见，桌面右侧精简浮层；移动端底部浮层。
- 日期切换、缺失日空输入、补录、修改；页内日期草稿可恢复，保存失败不清空输入。
- 真实写入成功后才返回允许演出的反馈；失败、账号切换和支持者角色均没有成功回执。
- 有烟记录播放约 1 秒记录脉冲和局部银粒回收，不称为无烟庆祝。
- 当今日保存使真实统计跨入 1/3/7/14/30/100 的精确节点时，播放约 2 秒轻光弧。重复保存相同零支记录不会重复触发节点反馈；补录/更正重新更新事实，不授予永久成就。
- 可跳过特效；隐藏页面、减少动态、交叉观察暂停、上下文丢失、退出路由均停止演出。

### 四类共同计划

| 类型 | 核验 | 空间表达 |
|---|---|---|
| 连续无烟 | 范围内真实逐日零支的最长连续段；缺失打断 | 分段棱晶节点 |
| 连续记录 | 连续日期有记录即通过，有烟也算 | 分段节点 |
| 吸烟上限 | 完整起止范围覆盖后核验实际累计支数；未覆盖待确认 | 覆盖进度银弧 + 微型圆节点 |
| 场景目标 | 戒烟者明确自主确认的日期；不根据打卡猜测吸烟时刻 | 空心小环与确认标记 |

- 计划范围 1–90 天；天数目标不能超过范围。
- 同屏只聚焦一个计划，其他计划保存在按需打开的短列表。
- `proposed → accepted → active → completed / missed`，以及取消、未接受提案过期的守卫与原因。
- 支持者可以提议、加入模拟陪伴；仅戒烟者可接受、激活、核验和自主确认。
- 修改提案增加版本并清除旧自主确认，重新接受；终止计划不销毁空间关系。
- 计划完成演出只在本页模拟状态成功转为 completed 时触发；重复核验 completed 不重播庆祝。
- 完成演出约 3.5 秒：局部光弧闭合、玻璃环与小棱晶凝聚。UI 明确为模拟纪念，未建立永久拥有记录。
- 补录/修改后活动计划自动按证据重算；缺失日期超过截止仍待证据，不把它当零支或强制判成功。

## 性能与限制

同机 Headless Edge 单次测量：

| 状态 | draw calls | triangles | GPU 记账几何体 | CPU render 提交耗时 |
|---|---:|---:|---:|---:|
| 空计划基线 | 43 | 45,514 | 32 | 1.5 ms |
| 7 节点计划完成演出 | 57 | 51,867 | 37 | 0.7 ms |

- GLB 保持 436,444 字节，6 个纹理计账；计划节点几何体共享，最多 90 个槽位，不每帧创建几何体。
- 鼓励回归采样 1,024 ms 内 61 次提交，约 59.6 次/秒；这不是实体手机 FPS 或 GPU 完成时间。
- 反馈几何体固定复用、结束隐藏、退出释放；此前动态鼓励粒子取消后恢复基线几何体数量。
- 无真实双账号/生产后端连接验收。本阶段没有为截图执行真实账号数据库写入；真实写入桥接和既有 persistence 单测通过，但线上权限/网络仍需授权账号验收。
- 支持者共享字段尚无明确隐私契约，因此此样板不开放被支持者的评分、感受、私人备注；只有身份权限提示与模拟体验。
- 参与者目前以角色记账，尚不是真实家庭成员 ID；共同计划不跨设备同步。
- 纪念只是瞬态可重建演出，尚未建立永久历史。不同高级里程碑的专用离线资产、支持轨道细分响应可在后续视觉迭代中深化。
- 本轮保留暗场版；玻璃和焦散仍是实时渲染近似，不宣称离线 CGI 一致。
