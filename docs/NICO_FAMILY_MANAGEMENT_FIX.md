# 家庭管理入口修复

原问题：个人中心「管理家庭」跳到 `/family`，该地址实际展示共生星图；星图的「家庭管理」再跳回个人中心，形成绕行。个人中心未展示既有邀请码，无法完成邀请闭环。

修复：

- 新增 `FamilyManagement.vue`，在个人中心「家庭关系」集中显示家庭名称、成员、本人/创建者、戒烟者/支持者和既有邀请码。
- 复制仅在 Clipboard API 成功后显示成功；浏览器限制时保留可选中的只读邀请码及手动复制提示。
- 刷新成员复用现有 `refreshFamily`；失败明确反馈，并暂时禁用依赖成员信息的退出操作，刷新成功后恢复。
- 退出家庭沿用原有确认、后端操作与账户缓存处理。
- 「前往共生星图」明确标注用途，不再冒充管理入口。
- 无家庭时保留原创建/加入表单；个人资料加载失败时不展示可创建表单。
- `ProfileView.vue` 同时处理初次加载和同一路径 `section=family` 查询变化，深链可定位到家庭关系。

后端没有既有家庭改名、移除成员、修改他人角色接口，本次不新增虚假入口，不改数据库、权限或 API。

验收：52 个单元测试文件、230 项测试及生产构建通过。浏览器隔离回归覆盖邀请码、复制成功/失败、刷新失败重试、退出确认取消、手机布局、同页深链及原业务流程。不执行真实家庭写入。
