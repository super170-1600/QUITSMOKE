# Phase 1 — 晶体主页面视觉骨架

> 这是 Phase 1 的历史实现记录。后续视觉质量重构、当前材质参数及截图请见 [Phase 1.5](HUB_PHASE15.md)。

## 实现范围

新增 `/hub`，沿用原 `requiresAuth`、家庭初始化、角色与戒烟设置检查。未修改路由守卫、App 的桌面跳转、登录逻辑、业务 store、API、数据库或统计公式。Landing 仍按之前的流程进入 `/home`，本阶段没有接入 Landing→Hub 转场。

Hub 使用 Vue 3 和现有 Three.js。真实几何由六个不等距主平面、十二个边缘倒角平面与八个不等深度切角平面求交，生成六个宽大主面和二十个过渡面。主面增加具有凸起截面的抛光光学边框。六个主面保持稳定 ID、外法线、中心及局部 UV；过渡面不绑定模块。几何是封闭多面体，所有边由两个面共享。

内部香烟含纸身、纸缝、滤嘴斑点、金属接缝、灰烬端、破损纸边及 28 个炭灰颗粒。六条透明曲线与三条薄片流线表现封印内部的微弱烟雾。香烟、烟雾与晶体共用中心层级，尚无独立旋转行为。

五个功能标识为真实半嵌入几何：打卡圆环与勾记、玻璃数据柱与金属线、八边金属徽章与星、三玻璃节点与连接、同心几何环与中央晶片。04 无标识、文字、业务组件或点击行为。

玻璃采用物理透射、厚度、IOR、程序化 HDR PMREM 环境与柔和灯光；精细金属边缘、凸起边框和少量程序化切面高光增强轮廓。背景使用冷银与暖白光层、三条透明几何飘带、底部椭圆光晕及锚定晶体角点的少量衍射光斑。背景和环境均由代码生成，无新图片资产、远程模型、新依赖或位图晶体外观。数据柱调整为银色立柱与暖金内嵌条，提高侧面辨识度。

## 与完整规范的差异

这是静态视觉骨架。尚无拖拽、惯性、磁吸、面片点击、焦点态、面标签、模块展开或业务挂载。Hub 不持续自动旋转，仅在非减弱动画环境进行非常轻的悬浮和内部呼吸。WebGL 失败时提供原首页链接，不伪造五模块导航。

几何采用切角六面体的可控不规则轮廓，不追求随机宝石形。透射与切面高光属于实时近似，尚未使用离线光追、复杂色散或后处理。没有实体底座。内部香烟从侧面自然呈现透视缩短，始终保持同一封印中心。

## Phase 2 准备

下一阶段可直接使用各面的 ID、中心、法线与局部坐标：加入 Pointer Events / quaternion 拖动、点击阈值、惯性阻尼、有效面磁吸和 Raycaster；04 始终不可激活。另加入可聚焦 HTML 等价控件、极短当前面名称、触屏手势范围、非法状态恢复，并继续调光学材质与侧面标识对比。
