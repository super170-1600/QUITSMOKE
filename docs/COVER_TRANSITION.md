# 首页光环入口

首屏使用高精度渲染底图、GPU 形变和实时颗粒组成 2.5D 场景。入口是左侧光环的圆形点击范围，无可见「开始」按钮。

点击后，镜头和地面保持固定，烟雾通过连续多层噪声与宽羽化边缘逐渐变薄，轻微气流扰动使局部轮廓飘散；香烟与黑色颗粒同步淡去。粒子使用柔软的烟尘光点，移除了三角网格、裂隙和硬质碎片。没有整图缩放和第二段移动。动画持续 1700ms，完成后导航到 `/home`，由原有路由守卫处理登录与初始化。

`src/visuals/coverLayout.ts` 的 `COVER_ENTRY_DURATION_MS` 同时控制 WebGL 进度、CSS 动画和导航计时。减少动态效果偏好或 WebGL 不可用时使用快速跳转。

消散时增强局部气流扰动和密度变化，在动画前 82% 内完成主体消散。地面烟灰通过独立下部遮罩同步过渡到无污染底图，额外的地面烟尘粒子向上飘散，避免底图中的黑色颗粒残留。

验证：`npm run build`、`node scripts/verify-cover.mjs`。浏览器检查涵盖入口点击范围、重复点击、移动端布局、键盘入口、减少动态效果和 WebGL 上下文丢失后的降级。
