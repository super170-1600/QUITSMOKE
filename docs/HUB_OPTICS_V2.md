# Phase 1.5：切面与外部空间光效 v2

本轮继续美术迭代，不是 Phase 2。最新资产版本 seal-study-02；本文取代 HUB_BLENDER_STUDY.md 中的旧尺寸和视觉参数，旧报告与截图保留。未修改业务逻辑、数据库、API、认证或权限守卫，也未增加 npm 依赖。

## 外壳重切与模块面

在 Blender 构建脚本中，对原导航壳的平面做三平面求交、半空间裁切并重新生成各面。保留原六个主面 faceId 和 navigationNormal，过渡平面沿法线内移 0.12–0.24 场景单位，使切角宽度明显不同。仍有六个主面与十八个过渡切面；每个面都是独立、有厚度、细倒角、局部原点的网格。没有增加边框模型。

主面面积（场景单位²）：打卡 2.308、数据 2.285、成就 1.571、04 预留 3.040、互助 3.282、个人 2.573。主面切割后不低于 1.5，并在导出与资产测试中检查。顶部面积最小，后续交互阶段仍需验证实际屏幕点击命中范围；本轮未实现点击。五个标识沿各面局部方向向中心回移 0.22，保持原造型与半嵌入深度；04 没有标识。

默认模型 Euler 角为 (.47,-.66,-.08)，相机 (0,.9,8.7)、垂直 FOV 32°。默认 overview 同时能看到 checkin、progress、achievements 三个朝向的主面。手机按包含外部轨道的 5.8 单位宽度适配，留出页头与外缘空间；实测截图中未裁切主体。

玻璃继续有 physical / hybrid 对照。默认 hybrid 为内部可见性优先：主面 alpha .27、metalness .08；过渡面 alpha .66、metalness .45，配合视角相关 Fresnel alpha，局部反射定义切角边界。没有把外壳改成乳白实体。**默认外壳仍是透明反射近似，并非真实多重折射玻璃**。physical 方案保留完整透射，但内部玻璃层的可见性仍弱，见验收对照。内部香烟、230 个黑色碎片、三条封印丝带和两片晶片保留。

## 独立外部光学系统

Blender 的 ExternalOptics 分组包括三条非闭合实体螺旋丝带：每条 160 段、12 点椭圆截面，最大宽度 .24 / .285 / .33、厚度 .018，带空间扭转和渐细端点；材质分别为银蓝与淡香槟金。GLB 携带独立网格和渐变 UV，网页通过 UV 与视角控制透明度；默认 alpha .72、metalness .45、clearcoat .9、环境反射倍率 1.3。这些参数用来强化曲面反射，并未添加 Bloom。

Three.js 的 hubPhotons.ts 建立独立世界空间系统：四个不同倾角的轨道，其中三个带有不同厚度的反射轨道实体（半径 .006 / .008 / .004）；轨道上分布不均的实例化光学颗粒。默认密度 1.2，即 120 个颗粒，上限 160；少数颗粒较大，另有三个局部脉冲闪光和短拖尾。粒子沿空间路径移动，轨道与外部丝带分别穿过主体前后；保留正常深度测试，不把效果绘制为永远盖在模型上方的 HUD。

地面有水平柔和接触阴影和暖色焦散近似。焦散是局部 shader 生成的细光纹，不是路径追踪焦散。关闭外部系统时一起关闭外部丝带、轨道、粒子、闪光、拖尾和焦散；接触阴影保留。

接口 `HubAssetScene.setPhotons(enabled, density?)` 可独立开关与调整密度。开发预览支持 photons=0/1、density=0–1.6；生产没有调试控件，也未增加按钮或侧栏。低密度验收使用 .35，实测绘制三角形数随粒子数量下降。密度仅控制光学颗粒；轨道与丝带数量固定。关闭效果不会重新加载或销毁全部资产，避免后续切换卡顿，但资源仍占内存。

FPS 测量条件：Headless Edge 133，ANGLE Direct3D11，Intel(R) UHD Graphics；1440×900、DPR 1，预热 1.5 秒、每项采样 5 秒。用实际执行的场景渲染回调数量除以采样秒数；关闭/开启时 rAF 中位间隔 41.7 / 50.0 ms，P95 为 89.6 / 70.9 ms；此次最终采样浏览器报告使用核显，不能沿用前一配置独显测得的约 240 FPS。**这不是 GPU timer 测量，也不是普通手机或用户可见窗口的帧率承诺**。手机只做视口布局预览，没有用实体手机测试性能。桌面实际 DPR 上限 1.75、手机 1.4；高 DPR 下性能会不同。

最终测试：28 个测试文件、125 项通过；vue-tsc 与 Vite 构建通过，仍存在已有的大 chunk / 混合动态静态 import 警告。截图采集无页面与 shader 错误；六面、三个可见朝向、光子开关和密度减少的绘制量都有自动断言。匿名九条受保护路由、公开封面、手机和 WebGL context loss 降级回归通过；未执行真实账户数据库写入。

## 本轮文件

- `scripts/blender/build_seal_study.py`：重新切壳、移动标识、实体外部丝带、离线轨道与颗粒、同尺寸离线参考。
- `assets/blender/quitsmoke-seal-study.blend` / `public/models/quitsmoke-seal-study.glb`：更新原生与网页资产；原生备份由 Blender 保留。
- `src/visuals/hubAssetScene.ts`：切面材质、默认相机、外部资产开关、水平阴影、运行时设置接口及渲染统计。
- `src/visuals/hubPhotons.ts`（新增）：独立轨道、实例粒子、局部闪光、拖尾与焦散近似。
- `src/views/HubView.vue`：开发预览参数，生产极简界面不变。
- `src/visuals/hubAsset.test.ts`：主面面积与法线稳定性、外部网格独立性、渐变 UV 与工作室排除验证。
- `scripts/verify-hub-optics.mjs`（新增）：本轮验收截图、开关/密度验证、性能采样和画廊。
- `docs/HUB_OPTICS_V2.md`（新增）：本报告。

重导出流程仍使用 `scripts/blender/export_seal_asset.py`，选择模型根树而不是评估工作室。构建样板脚本会覆盖样板资产，人工修改 .blend 后应运行 export 脚本，避免重建覆盖美术修改。

## 尚未达到的视觉目标

轮廓与空间光效比前轮更明确，但仍未完全呈现封面的丰富 CGI 反射、暖色折射与地面焦散。默认实时外壳有较明显的灰蓝反射面，宽丝带有些角度仍偏银色金属，透明层的准确排序与多次折射存在近似。三条围绕外壳的宽带是实体光学结构；轨道只是辅助，不应继续用更多细线填满画面。

本轮只提交可验收视觉迭代及实测证据。停止于 Phase 1.5，等待视觉验收，不进入自由翻转、磁吸定位、面展开或业务重构。
