# Phase 1.5：晶体边界、香烟消散与有序光环

本轮响应三个视觉问题：主体存在感不足、香烟消散焦点弱、轨道交叉过密。保留六个独立面、faceId、navigationNormal、面原点与五个标识，04 空白。没有进入 Phase 2，没有修改业务、认证、API 或数据库，未添加依赖。

## 调整

1. 主面 alpha .27、过渡面 .66 保持不变。在 Blender 导出每面的局部 opticalOutline，实时 shader 根据离边界的距离生成约 .010 场景单位宽的光学高光；只局部提高边界的反射与覆盖率，没有整体增加不透明度、粗框或 Bloom。背景右侧从 #d8dce0 调整为 #cbd2d8，左侧保持暖白；环境中补一块暗反射卡，让亮边有对照。这是边缘着色近似，不是真实多次折射。
2. Blender 中内部 core 放大 17%，增加正向倾角，保留破碎纸端与 230 个静态黑色碎片。实时新增 64 个低面数碎片，从末端沿曲线向上逸散并缩小；两条银白气流围绕逸散路径，末端有小范围暖光与柔和闪烁。核心效果与外部光子开关独立，关闭外部光效仍保留香烟消散。
3. 四条轨道分成两组连贯路径：下方暖金为恢复、上方银蓝为净化，组内倾角与半径接近、组间分开，减少中央交叉。暖金粒子缓慢正向运动，银蓝粒子以略快速度反向运动；闪光和拖尾保持对应颜色。每条轨道仍为非闭合曲线，端点的开口是设计留白；连续 TubeGeometry 提高到 256 段、8 点截面，改善原来的折线感。三条实体外部丝带保留宽度、厚度和渐隐，但重排为较一致的螺旋方向。

## 与封面的关系

检查了 sculptureScene.ts：封面的光学细节主要来自预渲染图片，其 shader 负责暖色光环、缓慢扰动、噪声消散以及地面灰烬清除。本轮采用它的视觉顺序：香烟末端局部暖光 → 黑色碎片脱离 → 沿银白气流逐渐变轻；光圈强调冷暖分工与连续空间路径。没有将封面图片贴在导航晶体上，也没有把平面光圈冒充可旋转的三维结构。

本轮仅做持续局部逸散，不触发整支香烟销毁、点击进入或页面切换。后续如需要完整消散，应以独立动画阶段处理真实模型和黑色碎片，保留现有导航面合同。

## 验证与限制

连续动画测试曾发现曲线采样越界。对帧时间差加非负限制，所有轨道与碎片相位使用 Euclidean modulo，保证反向、长时间运行和帧时序变化时相位仍在 [0,1)；新增负时间、反向和长时间的开放曲线采样测试。29 个文件、126 项测试通过，构建通过（仍有已有大 chunk / 混合 import 警告）。浏览器验收检查六面与三个可见方向、shader 错误、密度和开关、真实渲染回调帧率；匿名受保护路由、公开封面、手机与 context loss 回归通过。没有真实账号数据库写入测试。

同机位截图能看到香烟放大和轨道重新排布，但最终是否具有所需的艺术品质仍由视觉验收决定。当前实时 hybrid 外壳依然是透明反射近似；封面预渲染图片的复杂焦散与折射没有被完整实时复现。离线图不包含网页专属的动态碎片、局部瞬态闪光和焦散 shader，不能当作网页品质证明。

最终连续动画采样无页面或 shader 错误。完整效果 109,772 三角形、102 draw calls；外部光效关闭时 62,600 三角形、86 calls（内部消散仍运行）。Intel UHD / Headless Edge / 1440×900 / DPR≈1，预热 1.5 秒、采样 5 秒，实测渲染回调帧率关闭 44.0、开启 39.3 FPS。不是 GPU timer 测量，没有实体手机帧率测试，不能据此承诺高 DPR 或移动端帧率。

结束于 Phase 1.5，等待验收。
